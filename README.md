# كلمات الضيوف — صفحة تهاني العرس 🤍

صفحة واحدة بمقاس ستوري انستقرام (عمودي). الضيف يكتب **اسمه** و**كلمته/تهنئته**،
وبعد الإرسال تطلع له صفحة شكر باسمه. العروسان يشوفون كل الكلمات من لوحة `/admin`.

مبني بـ **Python + Flask**. جاهز للتشغيل محلياً وللنشر على **Railway**.

---

## 1) تشغيله على جهازك (Local)

تحتاج Python 3.10 أو أحدث.

```bash
# داخل مجلد المشروع
pip install -r requirements.txt
python app.py
```

بعدها افتح المتصفح على:

- الصفحة الرئيسية للضيوف: `http://127.0.0.1:5000/`
- لوحة كلمات الضيوف (للعروسين): `http://127.0.0.1:5000/admin`
  - كلمة المرور الافتراضية: `admin1234`

---

## 2) غيّر الأسماء والصورة

**الصورة:** استبدل الملف `static/background.jpg` بصورتك (يفضّل عمودية بمقاس قريب من 1080×1920).
خلّ نفس الاسم `background.jpg` وبس.

**الأسماء والنصوص:** أسهل طريقة عبر المتغيرات البيئية (أو بدّلها مباشرة أعلى `app.py`):

| المتغير | الوظيفة | الافتراضي |
|---|---|---|
| `COUPLE_NAME` | أسماء العروسين | `سالم & نورة` |
| `EVENT_TITLE` | العنوان الصغير فوق | `كلمات الأحبّة` |
| `EVENT_SUBTITLE` | الجملة تحت الأسماء | `اكتب كلمة تبقى ذكرى` |
| `ADMIN_PASSWORD` | كلمة مرور لوحة الإدارة | `admin1234` |
| `SECRET_KEY` | مفتاح الجلسات (غيّره لأي نص عشوائي) | — |

مثال تشغيل محلي بأسماء مخصّصة:

```bash
COUPLE_NAME="سالم & نورة" ADMIN_PASSWORD="1122" python app.py
```

---

## 3) النشر على Railway

1. ارفع هذا المجلد على مستودع GitHub.
2. في Railway اضغط **New Project → Deploy from GitHub repo** واختر المستودع.
3. Railway يتعرّف على المشروع تلقائياً (عبر `requirements.txt` و `Procfile`) ويشغّله.
4. من تبويب **Variables** أضف الأسماء وكلمة المرور:
   `COUPLE_NAME` ، `EVENT_TITLE` ، `EVENT_SUBTITLE` ، `ADMIN_PASSWORD` ، `SECRET_KEY`.
5. من **Settings → Networking** فعّل **Generate Domain** عشان يطلع لك رابط تشاركه مع الضيوف.

> لا تحتاج تضبط المنفذ — Railway يمرّره تلقائياً عبر `PORT` والتطبيق يقرأه.

### مهم: حفظ الكلمات بشكل دائم على Railway
الكلمات تُحفظ في ملف قاعدة بيانات `messages.db`. نظام ملفات Railway مؤقّت،
يعني لو أعدت النشر (Redeploy) بينمسح الملف. عشان تحفظها بشكل دائم:

1. أضف **Volume** للخدمة من Railway (مثلاً على المسار `/data`).
2. أضف متغيّر بيئي: `DATA_DIR=/data`.

بهذا تنحفظ قاعدة البيانات داخل الـ Volume وما تنمسح مع إعادة النشر.

## الروابط باختصار

| الرابط | لمن | الوصف |
|---|---|---|
| `/` | الضيوف | يكتب اسمه وكلمته |
| `/admin` | العروسان | يشوفون كل الكلمات (يطلب كلمة المرور) |
